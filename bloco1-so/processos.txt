# PARTE C — Questões de síntese

# 1. O campo PPID em /proc/$$/status indica o processo pai do shell.
#    Execute ps -o pid,ppid,cmd e localize o par shell -> processo pai.
#    O que esse encadeamento sugere sobre como os processos sao
#    criados no Linux?

Resposta 1:
O PPID 1 criou o PID 47 (seu Shell).
O PPID 47 criou o PID 86 (o comando ps).
isso mostra q um processo é sempre criado por outro, como uma relação de paternidade.
Diz tbm q o PPID é o pai supremo, sendo o primeiro processo do Boot.


# 2. O arquivo /proc/<PID>/status mostra o campo State com uma letra
#    (S, R, Z...). Depois de executar kill $FILHO e rodar ps novamente,
#    o que aconteceu com o processo filho? O que isso te faz pensar  
#    sobre a vida de um processo?

Resposta 2:
O Processo filho foi exterminado, removido da tabela de processos, oq indica q a vida de um processo é na verdade finita e baseada em eventos e controlada pelo sistema operacional.
