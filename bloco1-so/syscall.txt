# PARTE C — Questões de síntese

# 1. A apresentação afirma que "instruções de I/O são privilegiadas".
#    Como um programa de usuário consegue fazer I/O sem executar
#    instruções privilegiadas diretamente? (mínimo 2 frases)

Resposta 1:
O programa de usuário acessa as funções de Input/Output sem de fato entrar no modo hardware chamando a função (systemcall), que altera o modo usuário para o modo kernel, permitindo que o núcleo do sistema acesse e execute essas funções restritas de forma segura e controlada.

# 2. Compare write(fd, buffer, tamanho) com o "programa de canal"
#    da apresentação: o que os dois têm em comum em termos de
#    responsabilidades?

Resposta 2:
Em ambos, o processo principal apenas "prepara o pedido" e deixa outro agente (Canal ou Kernel) fazer o trabalho pesado. Ambos precisam saber onde buscar a informação, para onde enviá-la e quanto enviar.
